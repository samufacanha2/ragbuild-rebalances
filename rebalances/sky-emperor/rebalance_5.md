9. Sky Emperor

	Sky Sun
	Max level : 5
	Prerequisite skills : Noon Blast level 3, Sunset Blast level 3, Enchanting Sky level 7
	Group : Active
	Type : Melee physical
	Target: Instant cast
	Recovers AP : 2
	Description : Can only be used while under the effect of Celestial Unity.
	Instantly releases the power of blazing sun, inflicts melee physical damage to surrounding enemies around the user.
	Deals additional damage depends on level of Sky Mastery user learned, user's base level and POW.
	Has a chance to trigger critical, the critical chance is the user's Cri.
	The effectiveness of critical modifier is applied by half.
	_
	[Level 1] : (1500 + (Sky Mastery level x 7))% Atk / 3 x 3 cells.
	[Level 2] : (3000 + (Sky Mastery level x 14))% Atk / 3 x 3 cells.
	[Level 3] : (4500 + (Sky Mastery level x 21))% Atk / 5 x 5 cells.
	[Level 4] : (6000 + (Sky Mastery level x 28))% Atk / 5 x 5 cells.
	[Level 5] : (7500 + (Sky Mastery level x 35))% Atk / 7 x 7 cells.

	Type : Melee physical
	Target: Single target
	Recovers AP : 2
