3. Abyss Chaser

	Abyss Flame
	Max level : 5
	Prerequisite skills : Magic Sword Mastery level 5, From the Abyss level 3
	Group : Active
	Type : Magic
	Target: Single target
	Recovers AP : 2
	Description : Creates flames centered on the target, inflicts fire property magical damage to the target and surrounding enemies around the target for 5 hits.
	At the same time, emits abyss flames centered on the user, inflicts fire property magical damage to surrounding enemies around the user for 3 hits.
	Deals additional damage depends on level of Magic Sword Mastery user learned, user's base level and SPL.
